# Learn@Home

Cadrage du site de l'association Learn@Home, projet réalisé pour l'agence Dev4U.

Learn@Home met en relation des élèves en difficulté scolaire avec des tuteurs bénévoles. Le site comporte cinq pages : connexion, chat, calendrier, gestion des tâches et tableau de bord.

## Livrables

| Livrable | Dossier |
| --- | --- |
| Diagrammes de cas d'usage | `livrables/1-cas-usage/` |
| User stories et critères d'acceptation | `livrables/2-user-stories/` |
| Maquettes desktop et mobile, navigation | `livrables/3-maquettes/` |
